# В данном репозиториии представлены коды для выполнения задания по дисциплине «Параллельные вычислительные системы»
* Запускать коды необходимо по отдельности.
* Если код запускается в среде программирования необходимо подключить Поддержку Open MP (параллельная версия) или не подключать (последовательная версия). 
* Также для запуска 2 задания требуеся в доп параметры явно указать флаг /openmp:llvm для поддержки директивы #pragma omp task, в остальных программах ниче указывать не нужно.
* При запуске программы также нуобходимо самостоятельно в коде указывать количество тоннелей.
